Capture · Annotate · Share — team guide

যেকোনো পেজের full screenshot নিন, তাতে markup / redact করুন, আর এক ক্লিকে নিজের Google Drive-এ পাঠিয়ে link copy করুন। নিচে feature গুলো আর Drive folder কীভাবে সেট করবেন — দুটোই আছে।

Toolbar-এ extension icon-এ click করলে ৪টা mode পাবেন — অথবা সরাসরি keyboard shortcut।

⏱ Popup-এ Instant / 3s / 5s delay দেওয়া যায় (full/visible-এর জন্য) — menu বা dropdown খুলে তারপর capture করতে কাজে লাগে।

✏️ Editor — markup ও export

Capture করলেই একটা editor tab খোলে। এখানে যা যা করা যায়:

▭ Box◯ Ellipse↗ Arrow ╱ Line✎ Pen▓ Highlighter T Text🔢 Step ①②③🌫 Blur / Redact
• Blur / Redact দিয়ে sensitive লেখা (নাম, ফোন, ট্রানজেকশন) ঢেকে দিন — bug report-এ খুব দরকারি।
• Step ①②③ tool নিজে থেকে নাম্বার বসায় — reproduce-এর ধাপ দেখাতে সোজা।
• Color picker · Undo/Redo · Zoom · Crop সবই আছে।
• উপরে URL + time bar বসে (চাইলে toggle) — সাথে Browser · OS · Viewport · DPR লাইন, bug report-এর জন্য পারফেক্ট।
• Export: PNG / JPG / PDF · Copy to clipboard · Print. PDF-এ URL-টা clickable থাকে।

☁️ Send to Google Drive MAIN

Editor-এর সবুজ “Send to Drive” button — image upload হয়ে shareable link অটো clipboard-এ copy হয়ে যায়।

  1. প্রথমবার click করলে নিজের Google account দিয়ে sign-in চাইবে → নিজের account select করুন।
  2. “unverified app” warning এলে → Advanced → Go to app → allow. (এটা আমাদের নিজেদের internal app, তাই safe।)
  3. ব্যস — upload হয়ে link copy হয়ে যাবে। এবার bug report / chat-এ শুধু paste করুন।
File কার Drive-এ যায়? — আপনি যে account দিয়ে sign-in করবেন, আপনার নিজের Drive-এই যায়। অন্য কারও Drive-এ যাওয়ার ভয় নেই।

⭐ নিজের Drive folder সেট করা (Settings)

নির্দিষ্ট কোনো folder-এ জমাতে চাইলে একবার সেট করে নিন।

  1. Extension icon → নিচে Settings (gear) → অথবা chrome://extensions → Details → Extension options।
  2. নিচে ☁️ Send to Google Drive সেকশনে যান।
  3. Target Drive folder ঘরে আপনার folder-এর URL পুরোটা paste করুন, যেমন:
    https://drive.google.com/drive/folders/1AbCdEf...
    (শুধু ID দিলেও চলবে। খালি রাখলে → আপনার Drive-এর root-এ যাবে।)
  4. Save settings চাপুন। ব্যস।
যেটা করতে হবে না: Settings-এ Drive সেকশনে যে “One-time setup / OAuth Client ID” ধাপগুলো লেখা আছে — ওগুলো skip করুন। Client ID আগে থেকেই বসানো আছে (সবার জন্য এক)। আপনাকে শুধু Target Drive folder দিতে হবে, আর কিছু না।
Team-এর সাথে share করবেন? — folder-টা একবার team-এর সাথে share করে রাখলে আপনি যে private link পাঠাবেন সেটা এমনিতেই খুলবে; “anyone with link” public করার দরকার নেই। (Screenshot-এ sensitive data থাকতে পারে, তাই public না করাই ভালো।)

🔒 Permissions ও privacy

Install-এর সময় Chrome যে permission গুলো দেখায় সেগুলো কেন — সংক্ষেপে:

সবচেয়ে জরুরি কথা: এই extension কোনো website-এর data পড়ে না। আপনি নিজে icon চাপলে বা shortcut দিলে শুধু তখন, শুধু ওই page-টার screenshot নেয় (activeTab)। "সব সাইটে ঢুকে data পড়ে/বদলায়" — এমন কিছু নেই।
