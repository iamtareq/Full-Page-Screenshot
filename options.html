☁️ Send to Google Drive

One-time setup (so the extension can upload to your Drive):
  1. Go to console.cloud.google.com → create/select a project.
  2. APIs & Services → Library → enable Google Drive API.
  3. APIs & Services → OAuth consent screen → set it up (External, add yourself as a Test user).
  4. Credentials → Create Credentials → OAuth client ID → Web application.
  5. Under Authorized redirect URIs, add exactly this:
    …
  6. Copy the generated Client ID and paste it below. Paste your target Drive folder (URL or ID) too.

On first use Google shows a consent screen asking for Drive access (needed to place files in your chosen folder), and — because your app is unverified/in testing — an “unverified app” warning: click Advanced → Go to (app) (unsafe) to proceed. This is your own app; it stays private to you.

OAuth Client ID
Ends with .apps.googleusercontent.com
Target Drive folder
Paste the folder's URL or ID. Leave blank to upload to your Drive root. Tip: share this folder with your dev/team once — then the private links you send just work, no public sharing needed.
Make links public (anyone with the link)
Off by default for privacy. Leave off if your folder is shared with the team. Turn on only if you send links to people outside the folder — screenshots can contain sensitive data.
